# FinQuant-Lab

一个通过每日任务，逐步学习金融、投资和公司知识的个人实践仓库。尽量结合真实数据，从一个概念、一道小练习、一份公司公告出发，积累分析方法，并记录真实投资中的决策与复盘。

这里既容纳十几分钟的入门练习，也容纳持续的公司研究和投资实践。重点是把知识讲明白、把数据查清楚、把判断过程留下来；不要求每天形成完整报告，也不要求每天交易。

## 学习方向

- **金融基础：** 利息、复利、通胀、风险与收益、股票、债券和基金。
- **公司与生意：** 商业模式、行业竞争、公司如何赚钱。
- **财务分析：** 阅读三张报表，理解利润、现金流、资产、负债和权益。
- **投资入门：** 估值、预期、价格与价值、分散投资和仓位管理。
- **投资实践：** 记录研究假设、实际决策和结果，区分判断质量与短期盈亏。

这些是逐步扩展的方向。内容从每天实际完成的练习中生长，逐渐积累成可供入门者参考的学习资料。

## 每天怎样更新

每天围绕一个问题学习或实践：可以是理解一个概念、算一个指标、读一份公告，也可以是复盘一次真实投资决定。

练习完成后，由助手根据当天的讨论、计算和材料整理成文，核对来源与数值，更新阅读索引，并提交、推送到仓库。学习者直接提供练习过程和想法即可，无需按固定格式填写。内容的篇幅和组织方式随问题而定。

整理后的内容应让没有参与讨论的读者也能理解：问题是什么、概念怎么理解、数据从哪里来、怎么算、结论能说明什么，以及还有哪些疑问。保留有价值的纠错过程，去掉聊天中的重复和项目维护流水账。小练习也可以成为一篇短而清楚的学习笔记；没有合适数据时，明确标注教学假设。

## 学习与真实投资

分别标明概念学习、真实数据练习、模拟观察和真实投资记录。真实数据也可以用于模拟练习，历史模拟记录不因项目定位扩展而变成真实交易。

涉及真实投资时，整理当时的信息、判断、风险和计划，再补充执行结果与复盘。继续观察、放弃机会和不交易也值得记录。没有提供的成交、持仓及收益不作假定；公开记录可使用仓位比例或匿名化金额，不上传账户凭证、账号等敏感信息。相关内容积累后再按需要归档。

上述苹果案例金额单位为百万美元；期间为财年前九个月，不能与单季度混用。模拟观察指学习用记录，财务数值取自所列 SEC 来源，不代表实际交易。其他任务应分别注明自己的数据口径。

## 记录约定

- 区分原始事实、计算结果、个人判断和待验证假设，结论应能追溯到材料。
- 缺失数据写“待核实”，不用零代替；比较时核对期间、单位和会计口径。
- 发现错误时写明更正及其影响；投资复盘保留决策当时的依据，后续变化另行追加。
- 单个指标或一次盈亏不等于完整结论。逐步联系生意、财务、估值和风险。
