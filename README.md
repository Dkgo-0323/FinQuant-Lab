## 怎样学习

按目录打开一期文档，先理解问题和例子，再对照数据用计算器算一遍。先自己做练习，再看参考答案。能够向别人解释“怎么算、为什么、还不能说明什么”，就可以进入下一期。

每一期不限定篇幅和学习天数。正文应能独立阅读，不要求安装工具或会编程；需要批量核对时才附复算脚本。

每期材料放在一起。小型数据表同时展示在正文中；较大数据放本期附件，正文列出直接链接。原始数值摘录不等于完整原始公告，须保留官方材料链接和定位；保存完整材料时也放在本期目录。

## 后续怎样更新

每期主题由学习者确定后，沿用[写作模板](LESSON_TEMPLATE.md)整理文档；完成一期，再更新目录。事实、计算、判断和待验证问题分开写；真实数据与教学假设明确区分。没有查到的数据写“待核实”，不拿零代替。原始数据保留期间、币种、单位、来源、定位和核对日期；计算保留公式、代入数值和舍入方式。

学习记录默认是研究练习。真实成交、持仓和收益只有在实际提供后才记录，公开资料不包含账户凭证等敏感信息。
