# 第002期｜公司的负债，都要拿现金还吗？

[返回课程目录](../../ROADMAP.md) · [上一期：利润与现金](../001-cash-flow/README.md)

原学习日期：2026-11-03；案例补充与来源核对：2026-11-06。

本期学会：区分负债的履行方式，亲手计算资产负债率，解释单个比率的局限。

## 先从会员店想起

你先交了一年的会员费，店还要继续为你提供服务。这笔钱虽然已收到，却不能全部立即算作已赚到的收入；未完成的服务形成一项负债。银行贷款则要按合同还本付息。它们都叫负债，履行方式却不同。

本期[原始数值摘录](data.csv)来自文末公告的资产负债表，单位为百万美元，时点为2026-08-30，未经审计；摘录并非完整公告。

今天的问题：公司的负债都需要拿现金偿还吗？资产负债率较高，就一定有严重财务风险吗？

## 三种负债，三种理解

| 项目 | 含义 | 通常如何履行 |
| --- | --- | --- |
| Accounts Payable：应付账款 | 商品已经收到，货款尚未支付 | 按约定向供应商支付现金 |
| Deferred Membership Fees：递延会员费 | 会员先付费，公司尚未提供完相应服务 | 在会员期内持续提供服务，逐步确认收入；符合退款条件时可能退还现金 |
| Long-term Debt：长期借款 | 向银行等机构借款或发行债券形成的债务 | 按合同现金还本付息 |

递延会员费的关键是“钱先收了，服务还没提供完”。它列为负债，是因为公司仍负有履约义务，不能把收到的全部现金立即当成已赚到的收入。

## 研究时先分清负债性质

可以先按经济性质分为三类，再逐项判断：

- **经营性负债：** 例如应付货款、应付工资、递延会员费。来自日常经营，可能需要支付现金，也可能通过提供商品或服务履行。
- **借款：** 例如短期借款、债券、一年内到期的长期债务、长期债务的非流动部分。重点看还本付息和再融资压力，计算时不要重复计入一年内到期部分。
- **其他负债：** 例如单列的租赁负债、递延所得税、预计负债，以及尚未拆分的其他项目。需要查附注了解性质、金额和结算时间。

这是一种分析方式。租赁在这里单列于其他负债，若计算含租赁的债务指标，应说明口径；供应链融资等安排需要看实质。无法拆分的“其他负债”应保留待核实标记，不能默认都是无息、低风险项目。

## 两个比率回答不同的问题

资产负债率＝总负债÷总资产；借款资产比＝借款÷总资产。前者看全部负债规模，后者看借款规模。完整借款口径需要查清短期借款、长期借款及其一年内到期部分等项目，不能把现金流量表中的本期借入或偿还金额当成期末借款余额。

资产负债率概括总负债规模，无法单独说明支付压力。先区分经营性负债、借款和其他负债，再查履行方式、到期安排、可用现金与持续现金流。经营性负债不能自动归为低风险。

## 为什么不能只凭59.8%判断严重风险

假设一家企业每100元资产对应59.8元负债，这只能描述账面结构。还需要知道：其中多少要现金偿付、多少通过服务履行，什么时候到期，以及企业有多少可用资金和持续现金流。

经营性负债同样可能造成压力：供应商缩短账期会加快现金流出，预收款可能面临退款或履约成本。借款较少也不能直接证明安全。反过来，总负债占比高，也不代表近期需要现金偿还同样规模的银行借款。

判断风险时，把负债性质、到期安排、不受限现金和经营现金流放在一起看，并检查经营所需资金、利息、必要资本支出和潜在义务。这篇笔记整理了分类方法，尚未对Costco全部负债逐项拆分，也不构成完整的公司风险结论。

## 练习材料

本次讨论从[Costco 2026财年业绩公告](https://investor.costco.com/news/news-details/2026/Costco-Wholesale-Corporation-Reports-Fourth-Quarter-and-Fiscal-Year-2026-Operating-Results/)中的 `CONSOLIDATED BALANCE SHEETS` 展开。继续研究时，应同时阅读借款、租赁和其他负债附注，核对数据时点与分类口径。

## 真实案例：把Costco的59.8%算出来

下面取公告2026-08-30一列；不要将现金流量表的全年借入额当成期末余额。

| 项目 | 百万美元 |
| --- | ---: |
| 总资产 | 89,045 |
| 总负债 | 53,242 |
| 一年内到期的长期债务 | 2,248 |
| 长期债务（扣除一年内到期部分） | 3,914 |
| 应付账款 | 22,591 |
| 递延会员费 | 3,006 |

```text
资产负债率 = 53,242 ÷ 89,045 × 100% ≈ 59.79%
已列示长期债务合计（含一年内到期部分）= 2,248 + 3,914 = 6,162
已列示长期债务占资产比 = 6,162 ÷ 89,045 × 100% ≈ 6.92%
```

59.79%说明每100美元账面资产对应约59.79美元负债。但其中已列示的长期债务只占资产约6.92%，不能把全部负债都理解为银行贷款。这不是完整有息债务统计：其他项目中是否包含借款、租赁和融资安排，仍需查附注；不能将53,242减去6,162后的全部余额都认定为无息经营负债。

这份公告足以演示分类和计算，还不足以完成偿债风险判断。下一步要查到期安排、其他负债附注、可动用现金以及持续经营现金流。

## 自己练习，再看答案

教学假设：会员店资产100万元，负债60万元，其中银行借款10万元、预收会员费20万元、应付货款30万元。

1. 资产负债率和银行借款占资产比分别是多少？
2. 能说这家店近期必须拿出60万元现金还银行吗？

<details>
<summary>参考答案</summary>

1. 60 ÷ 100 = 60%；10 ÷ 100 = 10%。
2. 不能。银行借款只是10万元，其到期时间还要查合同；应付货款通常付现金，会员费主要通过服务履行，也可能涉及退款和服务成本。

</details>

带走一句话：看到负债，先问欠的是什么、怎么履行、什么时候履行。
